 Project_ISP241_V5
Проект по пятому варианту words.
 Поиск слов в матрице

Программа на Java 17 создаёт матрицу с десятью случайными словами из файла words.xml. Используются элементы item из массива string-array с именем words. Остальные ресурсы XML не участвуют в выборе.

 Запуск проекта

Нужны JDK 17 и терминал с поддержкой UTF-8. Команды выполняются из папки проекта:

```powershell
[Console]::OutputEncoding = [Text.Encoding]::UTF8
javac -encoding UTF-8 Words.java
java Words 10x10
```

Первый аргумент — ширина и высота: 10x10, 11x10, 10x11, 12x10 или 10x12. Второй необязательный аргумент задаёт путь к XML, по умолчанию используется words.xml. Третий необязательный аргумент — целое начальное число генератора, позволяющее повторить результат при тех же входных данных.

Программа выводит матрицу, начальное число и список только тех слов, которые в неё попали. При ошибке выводится сообщение и возвращается код 1.

 Алгоритм

1. Читаем XML, переводим русские слова в верхний регистр и удаляем повторы. В списке должно быть не меньше десяти различных слов.
2. Перемешиваем словарь и выбираем слова случайным образом.
3. Проверяем все возможные прямые отрезки в случайном порядке. Слова размещаются по горизонтали, вертикали и диагонали в обоих направлениях. Пересечения разрешены при совпадении букв.
4. Если слово не помещается или нарушает единственность вхождения, пробуем слова меньшей длины из оставшегося списка. Сначала проверяем самые длинные из более коротких, при равной длине порядок случайный.
5. После размещения десяти слов заполняем свободные клетки случайными русскими буквами. Проверяем, что каждое выбранное слово встречается ровно один раз. Палиндром на одном отрезке учитываем один раз.
6. При неудаче повторяем генерацию. После 500 попыток сообщаем об ошибке.
